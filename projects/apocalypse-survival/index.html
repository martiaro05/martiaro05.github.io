Apocalypse Survival

2018 • JavaScript

Apocalypse Survival is my first project — a two-character zombie defense game where players prevent zombies from crossing the gray line. Each time a zombie is shot, their speed increases.

I made the project in Processing 5 (P5.js), a JavaScript framework built for creative graphics coding.

Controls: W, A, S and Arrow keys.
